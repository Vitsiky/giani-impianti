# Giani Impianti

Sito Next.js (App Router, Tailwind v4) per Giani Impianti — idraulica, riscaldamento e climatizzazione a Montespertoli, Toscana.

## Sviluppo locale

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

## Deploy

Progetto Vercel `giani-impianti` (scope `vitsikys-projects`), collegato al repo GitHub: ogni push su `master` fa deploy automatico in produzione su [gianiimpianti.com](https://gianiimpianti.com).
